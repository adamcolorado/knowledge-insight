Phenomenology for Consciousness Studies

Vetting status

This program is published while expert review is still underway. The content is complete and the sources are linked, but it has not yet been validated end to end.

What the seals mean

A fully vetted program has completed human-in-the-loop review: a subject-matter expert has validated every learning item and every source in it.

An in-progress program is published while that review is still underway. We release early because the material is useful early, and because readers catch things that reviewers miss. Every page of an in-progress program says so, and tells you how to report what you find.

Help us vet this program

You are reading it closely anyway. If something looks wrong, please tell us to help improve the program.

  • Check claims against the linked sources. Every reading names where its ideas come from. If a passage misstates a source, or attributes something to the wrong thinker, say so and point to the item.
  • Report broken or wrong links. Free editions move and paywalls change. A dead link is worth reporting even when the text around it is fine.
  • Flag quiz questions that do not hold up. An answer you can defend that is marked wrong, an option with no good answer, or feedback that misses the point.
  • Suggest improvements. A passage that reads as muddled, an example that would land better, a primary text we should have pointed you to.
